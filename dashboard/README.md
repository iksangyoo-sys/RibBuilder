# 차체공정 정비비 지표현황 대시보드

`index.html` 하나로 동작하는 임직원용 대시보드입니다. 같은 폴더의 `data.xlsx`를 읽어 분석합니다.

## 실행

브라우저 보안 정책 때문에 `index.html`을 더블클릭(file://)하면 `data.xlsx`를 자동으로 읽지 못합니다. 아래 중 하나로 여세요.

1. **웹서버로 열기 (권장)** — 이 폴더에서 아래를 실행한 뒤 `http://localhost:8000` 접속
   ```
   python -m http.server 8000
   ```
   사내 웹서버나 공유 웹폴더에 `index.html`과 `data.xlsx`를 함께 올려도 됩니다.
2. **파일 직접 선택** — 화면의 [엑셀 열기] 버튼이나 끌어다 놓기로 `data.xlsx`를 선택

## 데이터 자동 갱신

- 웹서버로 열면 60초마다 `data.xlsx`가 바뀌었는지 확인하고, 바뀌면 화면을 다시 그립니다 (필터 선택은 유지).
- Chrome·Edge에서 [엑셀 열기]로 선택한 파일도 같은 방식으로 자동 갱신됩니다. 끌어다 놓은 파일은 자동 갱신되지 않습니다.
- 확인 주기, 시간당 단가(60천원), 비계획 작업구분 목록은 `index.html` 스크립트 맨 위 설정값에서 바꿉니다.

## 데이터 처리 규칙

- 읽는 시트: `data` (없으면 `작업일자` 컬럼이 있는 첫 시트)
- 필수 컬럼이 없으면 어떤 컬럼이 없는지 안내하고 멈춥니다.
- 필수 값이 비었거나 날짜·숫자를 해석할 수 없는 행은 제외하고, 상단 배너에 제외 건수와 엑셀 행 번호·사유를 표시합니다.
- 긴급가산율·부품비 빈 값은 0, 정산공수·총정비비 빈 값은 산식으로 계산합니다. 입력된 값이 산식과 다르면 입력값을 쓰고 불일치 건수를 표시합니다.
- `담당자`·`Source.Name` 컬럼은 읽지 않습니다 (개인정보 보호).
